# 𝓡𝓾𝓲𝔃𝔻 导航

个人导航主页，包含三部分：

- **index.html** — 主页面（时钟、天气、搜索、导航分类、音乐播放器）
- **nav-all.html** — 导航大全（16大分类、200+常用网站）
- **nav-work.html** — 工作导航（技术开发、工具服务等分类）
- **music-player.html** — 纯音乐播放器

## 使用说明

双击 `index.html` 即可在浏览器打开使用。

部分功能需联网（天气、一言、音乐播放等）。

## 技术栈

- 纯 HTML + CSS + JavaScript
- 毛玻璃（Glassmorphism）设计风格
- 本地存储（localStorage）保存自定义设置
