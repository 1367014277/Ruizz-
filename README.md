> **融合毛玻璃美学 × 智能聚合 × 全栈自研**  
> 不止是导航，更是你的数字生活入口。

## ✦ 项目简介

𝓡𝓾𝓲𝔃𝔃 Navigation 是一款**全功能浏览器起始页与导航系统**，采用前沿的 Glassmorphism（毛玻璃）设计语言，集信息聚合、智能搜索、影音娱乐、效率工具于一体，旨在为用户提供沉浸式、高效率的上网起始体验。

---

## ✦ 核心模块

### 🏠 主控面板 — `index.html`
| 组件 | 说明 |
|------|------|
| ⏰ **智能时钟系统** | 实时数字时钟 + 日历组件 + 农历信息 |
| 🌤️ **天气感知模块** | 基于位置的实时天气数据与问候语 |
| 🔍 **多引擎聚合搜索** | 百度 / Google / Bing / B站 / 知乎 一键切换 + 智能联想 |
| 🗂️ **动态导航网格** | 7大分类、63+常用站点，支持右键编辑 / 添加 / 删除 / 拖拽排序 / 分类迁移 |
| 🎵 **沉浸式音乐播放器** | 网易云音乐完整曲库 + 电台模式，30s预览备用 |
| 🔥 **热搜资讯看板** | 实时聚合全网热点，固定高度500px，自适应对齐 |
| 💬 **一言组件** | 随机名言，固定高度160px，「换一条」按钮沉底 |
| 👤 **头像/昵称编辑** | 右键头像可本地上传 / 输入链接 / 恢复默认，昵称可右键编辑 |
| ⚙️ **全参数设置中心** | 字体 / 颜色 / 背景 / 透明度 / 毛玻璃强度 / 组件开关 / 布局拖拽排序 |
| 🎯 **响应式适配** | 完美适配1920×1080，其他分辨率自动缩放（minmax侧栏逐级缩栏，1024px以下单栏） |
| 📜 **底部滚轮条** | 缩放窗口时底部出现自定义水平滚动条，支持拖拽滚动 |
| 🔘 **副导航独立开关** | 大全/工作按钮可分别控制显隐 |

### 📚 导航大全 — `nav-all.html`
囊括 **16 大分类、200+ 精选网站**，覆盖 AI 工具、程序开发、设计素材、学习教育、影音娱乐、资源下载、社交社区、生活便民、电商购物、网络工具、游戏娱乐、医学健康、财经理财、数码科技、美食烹饪等全领域。支持**右键自定义编辑**，快速导航栏点击展开/折叠分类，右键可添加新类别，数据云端持久化存储。

### 💼 工作导航 — `nav-work.html`
专为技术工作者打造的高效导航面板，汇集技术开发、工具服务、设计创意、AI 工具等核心生产力站点，助力工作流零切换。支持快速导航栏点击展开/折叠分类，右键添加类别。

### 🎧 纯音播放器 — `music-player.html`
极简主义独立音乐播放器，专注听觉体验。

## ✦ 技术架构

| 层级 | 技术选型 |
|------|----------|
| 🎨 **UI 引擎** | 纯原生 CSS3 — Glassmorphism 毛玻璃体系、Grid/Flexbox 响应式布局、CSS 变量主题系统 |
| ⚡ **交互层** | 原生 JavaScript ES6+ — 零依赖、高性能 |
| 🗃️ **数据层** | localStorage 本地持久化 + JSON 序列化 |
| 🌐 **服务集成** | 网易云音乐 API · iTunes API · 高德天气 API · 一言 API · 60s API |
| 🎯 **设计系统** | 自定义 CSS 变量体系（颜色 / 透明度 / 模糊强度 / 字体） |
| 📦 **部署** | 静态页面，支持任意 Web Server / GitHub Pages / Gitee Pages |

## ✦ 快速开始

```bash
# 无需构建，无需安装，开箱即用
```

## ✦ 自定义配置

所有个性化设置均通过**可视化设置面板**完成，无需编辑代码：

- 🎨 主题色 / 字体 / 背景图 / 毛玻璃透明度与模糊强度
- 🔍 搜索引擎 / 搜索栏样式
- 🎵 音乐源切换（网易云 / iTunes）
- 🧩 小组件显隐与拖拽排序
- 📑 导航分类与链接自定义
- 👤 头像/昵称右键编辑（本地上传 / 输入链接）
- 🔘 副导航（大全/工作）按钮名称修改与独立开关控制显隐
